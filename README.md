# 🐞 Intelligent Software Defect Tracking System

An interactive web-based platform for software defect tracking, analytics, KPI monitoring, bug life-cycle analysis, sprint and module analysis, team performance monitoring, and intelligent defect resolution assistance.

## 🌐 Live Dashboard

[🚀 Open Intelligent Software Defect Tracking System](https://intelligent-software-defect-tracking-system-xxxtmtpcwdvnzxy9ab.streamlit.app/)

The application is deployed using Streamlit Community Cloud and can be accessed directly through a web browser.

## 📌 PROJECT OVERVIEW

The Intelligent Software Defect Tracking System provides a centralized platform for monitoring and analyzing software defects.

The application combines data preprocessing, interactive visualizations, KPI monitoring, defect life-cycle analysis, sprint and module analysis, team performance tracking, data exploration, and intelligent resolution assistance in a single dashboard.

## ✨ KEY FEATURES

- 📊 **Overview** – Complete defect summary and project KPIs
- 🔄 **Life Cycle & Trends** – Defect status, closure trends, resolution time, and root-cause analysis
- 🏃 **Sprint & Module** – Sprint-wise and module-wise defect analysis
- 👥 **Team Performance** – Team performance and closure-rate monitoring
- 🧠 **Resolution Assistance** – Interactive defect analysis and intelligent assistance
- 📋 **Data Explorer** – View, filter, and explore defect records
- 📤 **Dataset Upload** – Supports CSV and XLSX files
- 🔎 **Filters** – Sprint and release-version filtering
- 📌 **KPI Monitoring** – Bug count, resolution time, critical defects, and closure rate
